# Kotoba Cloud — verified white-hat research

Security-focused LLM inference for authorized code review, vulnerability triage and remediation.
Status: LIVE. Identity verification runs on Stripe Identity only (no manual review queue).
One Stripe Identity verification approves the account automatically: ekyc, screening, trust, scope and activation.

Free allowance after verified identity: 50 requests per day, up to 2,048 output tokens per request. No automatic paid fallback.

Registration steps the agent can drive (human completes the Stripe identity check):
- Full registration guide: https://kotoba.cloud/ekyc.md
1. Sign in at https://auth.kotoba.cloud/sign-in — any method works and yields the
   same Stable Principal (identity method does not affect verification):
   - Passkey (Face ID / Touch ID / Windows Hello), or
   - Your own key: self-minted CACAO (`kotoba cacao --aud https://auth.kotoba.cloud`), or
   - Ethereum wallet (SIWE) or Base Account, or
   - Recovery phrase (BIP-39, derived in-browser).
   The session cookie (`credentials: "same-origin"`) is what the research API reads.
2. POST https://api.kotoba.cloud/v1/research/ekyc/start (same-origin JSON:
   {"scopeId":"owned","tasks":["code-review"]}) → verificationUrl
3. Human opens the verificationUrl (https://verify.stripe.com) — agents never complete the identity check themselves.
4. Approval is automatic on Stripe webhook; then GET /v1/research/status → eligible.
5. POST /v1/research/jobs (Idempotency-Key uuid) and poll GET /v1/research/job?jobId=.

- Model catalog: https://kotoba.cloud/v1/models
- Registration page: https://kotoba.cloud/#research-register
